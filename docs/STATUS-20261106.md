## 采集App已经完成

版本code16 / 0.3.5-capture-ui，安卓包名com.egouvc.phone；2UQ2原始双目3840×1080 MJPEG、左右各1920×1080；头环USB UVC XU IMU和USB音频，不是蓝牙或手机IMU。

- 现代中英文界面、固定采集按钮、保存详情、设备诊断及独立IMU检查。
- 连续预览保持5–10FPS目标并显示实际绘制帧率；code15修复双预览图层叠影，用户确认正常。
- code16移除主界面相机标定卡片、结果弹窗和内置历史报告，用户确认正常。相机标定和历史原件仍在工作站。

- 真实媒体左右各286帧完整解码；WAV48kHz双声道PCM16、1774080字节非全零，时长9.24秒。
- IMU名义SI导出7364行与原始计数一致；526包，每包14行；加速度m/s²、角速度rad/s。四元数字段0表示未提供姿态。
- 历史code16工作站完整构建23秒、14套件40项JUnit测试全部通过，签名与既有安装版本一致。

本次源码来自完整USB音频交付、经摘要核对的code11 SI overlay、code16 UI overlay三层合成，源码清单另存采集仓库。没有把远端旧code5误当作已安装最新版。当前同步环境未重新运行完整Android Gradle/NDK构建，不声称重新生成APK与历史APK逐字节相同。

## 采集App剩余项

原IMU计数仍发现25处间隙、估计406个样本位置缺失（约5.225%）；并非已证明导出丢行。包级宿主时间不能替代经验证的逐样本设备采样时间。硬件曝光/IMU同步、联合标定重复性尚未通过。长时、导出期间重插和前后台恢复仍待专项验收。视频30FPS为保存目标，已核对记录最大帧间隔67.387604ms，不宣称严格恒定30FPS。
