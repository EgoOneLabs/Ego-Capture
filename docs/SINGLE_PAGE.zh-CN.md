# 单页采集界面（code19）

浅蓝渐变背景、半透明玻璃卡片、细亮边框、轻阴影，蓝色渐变开始按钮与浅红停止按钮。竖屏固定一页，不提供滚动或第二个页面。

左画面固定在左、右画面固定在右，同一行等宽，不再上下排列。每块预览按 16:9 自动确定高度，卡片贴合两幅画面，不再用竖长面板填满页面。内容整体在页面中垂直居中，固定一页。画面完整显示，保持比例。

从上到下：标题与中英文切换、左右并排双目画面、任务名称与设备编号、目标保存帧率、开始采集与停止并保存、手机保存路径。

连接已授权的头环后自动打开相机，同时开始空闲 IMU 读取。开始采集时先结束空闲读取，再由录制线程读取并保存 IMU；停止采集后恢复空闲读取。拔线会关闭相机，本地保存和导出继续。导出期间两个录制按钮不可用，停止按钮显示“保存中…”，完成后显示正式会话路径。

首次使用仍需允许安卓的相机、录音和 USB 授权。拒绝后不会反复弹窗，可轻触预览区域重试。打开 App 后连接头环使用；未运行 App 时不承诺后台自动采集。自动连接不等于自动开始录制。

输入名称时键盘占用屏幕，暂时隐藏保存路径，预览自动缩小；收起键盘后恢复。录制期间锁定名称和帧率。输出路径可以长按复制。中英文切换不修改用户输入和磁盘文件。

## 数据文件

沿用 code16 的原始 Episode 与正式导出目录、视频几何、时间记录、IMU 名义 SI 换算和音频输出。界面不再显示统计，但诊断文件继续保存。此版本没有更改 IMU 时间定义、补样、相机曝光同步或标定结论。

## 手机验收

1. 安装后打开，允许权限，连接头环；不用点击打开相机即可看到左右画面。
2. 检查中文、英文均不滚动，名称和帧率可设置；软键盘收起后控件完整。
3. 录制约 15 秒，停止；保存中不能重复开始，完成后仅显示手机正式路径。
4. 再录制一次，停止后在导出期间拔线；仍须结束导出并显示路径。
5. 重新连接；预览和 IMU 自动恢复，开始另一条录制，确认文件包含 IMU 和音频。
6. 在空闲与录制中分别拔线；相机关闭，页面可继续操作，不停在旧进度。
7. 从日志检查空闲 IMU 启动，正式录制时无第二路空闲读取；检查输出样本和原始文件。

本次自动测试不代替以上手机验收。完整 APK 构建与真机结果由构建清单记录。

## code19 布局修正

修复 code18 中两块预览框过高产生的大块黑边。输入时按键盘可用空间收缩预览，收起键盘后恢复 16:9。统一半透明卡片、圆角边框、焦点描边和按钮按压涟漪。玻璃质感通过轻量渐变与透明度实现，不对实时图像施加模糊，也不改变采集文件。
